# Проект “Проектный семинар”

Интернет-магазин электроники, реализованный на Vue 3 по [макету]([https://www.figma.com/design/uwgOevC6NDmS73eG6lEPmG/](https://www.figma.com/design/EQC47Bzy09sBIVIj7iF3ij/%D0%98%D1%82%D0%BE%D0%B3%D0%BE%D0%B2%D1%8B%D0%B9-%D0%BF%D1%80%D0%BE%D0%B5%D0%BA%D1%82-%22%D0%9F%D1%80%D0%BE%D0%B5%D0%BA%D1%82%D0%BD%D1%8B%D0%B9-%D1%81%D0%B5%D0%BC%D0%B8%D0%BD%D0%B0%D1%80%22?node-id=2-2&t=sYjzDJjRgB7ZUjZ3-1)).

## Стек

Vue 3, JavaScript, Vite, Vue Router, Pinia, CSS, Lucide. Данные загружаются из [бэкенда](https://github.com/Arsen4ik/apple-store-backend/tree/build).

## Запуск

**Терминал 1 бэкенд:**

```bash
git clone -b build https://github.com/Arsen4ik/apple-store-backend.git
cd apple-store-backend
npm install
npm run serve
```

**Терминал 2 фронтенд:**

```bash
npm install
npm run dev
```
